LIFT LOG - Android app
======================

This folder is a ready-to-install web app (a PWA). It works offline once opened.
It must be put on the internet over HTTPS once, so your phone can install it.
Free option: GitHub Pages.

1. On github.com, sign in and tap "New repository". Name it lift-log, set it to Public, tap Create.
2. Tap "uploading an existing file". Upload ALL the files from this folder
   (index.html, sw.js, manifest.webmanifest and the four .png icons). Tap Commit changes.
3. Open the repository's Settings > Pages. Under "Branch" choose main and / (root). Tap Save.
4. Wait a minute. The page shows your address, like https://YOURNAME.github.io/lift-log/
5. On your Android phone, open that address in Chrome. Tap the menu (three dots)
   and choose "Install app" (or "Add to Home screen"). Lift Log now opens like any other app.

Your workouts are stored on the phone. Use Plan > Settings > Save a backup now and then.
To update the app later, upload the new files over the old ones.
